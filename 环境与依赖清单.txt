七、注意事项
--------------------------------------------------------------------------------
1. CUDA 版本匹配
   torch 2.6.0+cu124 内置 CUDA 12.4 运行时，本机驱动（610.74，支持 CUDA 13.3）
   向下兼容，无需单独安装 CUDA Toolkit 或 cuDNN，也不需要配置环境变量。

2. 预训练权重缓存
   首次运行时自动下载，缓存在
   C:\Users\33432\.cache\torch\hub\checkpoints\
     · resnet18-f37072fd.pth   （约 45 MB，第二/三/四/五步都用）
     · alexnet-owt-7be5be79.pth（约 233 MB，第二步用）
   离线环境下可提前把这两个文件拷进上述目录。

3. 无 GPU 时的回退
   所有脚本都会自动检测设备（torch.cuda.is_available()），无显卡时回退到 CPU，
   代码无需修改，但训练耗时会增加数倍。

4. matplotlib 中文字体
   绘图脚本已设置 font.sans-serif = Microsoft YaHei / SimHei，避免中文显示成方块。
   若在 Linux 或容器中运行，需先安装中文字体或改用英文标签。

5. 随机种子
   全部实验固定随机种子为 42（数据划分 / torch / numpy / random），
   同一环境下可原样复现报告中的准确率。

6. 跨平台说明
   本清单为 Windows 环境实测版本。迁移到 Linux 时，PyTorch 与 torchvision 需
   重新安装对应 CUDA 版本的 wheel，其余纯 Python 库版本可直接沿用。

7. 网页版的额外要求
   网页版是纯静态的，不依赖上述 Python 环境，但：
   · 必须通过 HTTP 服务访问（不能用 file:// 直接打开），见 serve_web.py
   · 浏览器需支持 WebAssembly（现代浏览器均支持）
   · 首次加载需下载约 22 MB（模型 10.8 MB + 推理引擎 11 MB），之后走浏览器缓存
