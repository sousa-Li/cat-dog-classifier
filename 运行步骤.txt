路线 C：本地打开 / 重新部署网页版
================================================================================

─── C1. 本地起服务器预览 ──────────────────────────────────────────────────
   python serve_web.py                       # 默认 http://127.0.0.1:8000
   python serve_web.py --port 8080           # 换端口

   然后浏览器打开 http://127.0.0.1:8000

   【为什么不用 python -m http.server】
   Python 自带的是 HTTP/1.0（每个请求都断连接），加载 onnxruntime-web 时会同时
   拉 .mjs 和 11 MB 的 .wasm，容易报
       TypeError: Failed to fetch dynamically imported module
   serve_web.py 改成了 HTTP/1.1 长连接 + 正确的 MIME 类型，不会出这个问题。

   【注意】直接双击 index.html 用 file:// 打开是【不行】的，
   浏览器安全策略会拦住模块加载和 wasm 实例化，必须通过 HTTP 服务访问。

─── C2. 浏览器自检（可选）─────────────────────────────────────────────────
   打开 http://127.0.0.1:8000/selftest.html
   它会自动加载模型、对 4 张示例图跑推理，把结果直接打印在页面上：
       SELFTEST_ITEM samples/cat_1.jpg truth=cat pred=cat ... OK
       SELFTEST_DONE
   用来确认浏览器端推理链路是通的。

─── C3. 重新部署到线上 ────────────────────────────────────────────────────
   改完模型后（比如重新跑了 step5_save_best.py），需要重新导出 ONNX：

   python export_onnx.py

   它会把 models/best_model.pth 导成 web/model/catdog_int8.onnx，
   并做两件事：
     · 逐张比对 PyTorch 与 ONNX 的输出，确认数值一致
     · 静态量化成 INT8，体积压到 1/4

   然后把 web/ 目录整个重新部署即可。

================================================================================
常见问题与排错
================================================================================

Q1: 报错 "No module named 'torch' / 'gradio'"
   → 虚拟环境没激活。回到第 0 步，或者直接用完整路径调 python.exe。

Q2: 报错 "找不到权重文件 ...\models\best_model.pth"
   → 先跑 python step5_save_best.py 生成它。

Q3: 报错 "目录里没有图片: ...\datasets"
   → 工作目录不对，先 cd 到项目根目录。

Q4: 报错 "size mismatch for fc.weight"
   → 如果你照抄了指导书第三步的代码，就会遇到这个。
     strict=False 不能解决形状不匹配的问题，正确做法见 README 第 4 节。

Q5: 中文在控制台显示成乱码
   → Windows 终端编码问题，不影响结果。运行前先执行 chcp 65001 切成 UTF-8。

Q6: 训练时提示 "CUDA out of memory"
   → 本项目显存占用不到 2 GB，一般不会遇到。真遇到就减小 batch_size。

Q7: 网页打开后一直显示"正在下载推理引擎…"
   → 首次加载要把 11 MB 的模型和 11 MB 的 wasm 下下来，网速慢时确实要等一会儿。
     之后浏览器会缓存。

Q8: 网页控制台报 "Failed to fetch dynamically imported module"
   → ort.env.wasm.wasmPaths 用了相对路径。必须用绝对 URL：
     ort.env.wasm.wasmPaths = new URL('ort/', location.href).href;

Q9: 网页直接用 file:// 双击打开报错
   → 必须通过 HTTP 服务访问，用 python serve_web.py。

Q10: 每次跑出来的准确率不一样
   → 检查有没有改 seed。固定 42 时可复现；不同显卡/不同 PyTorch 版本下
     浮点运算顺序略有差异，会有极小浮动，属正常现象。

Q11: 预训练权重下载卡住
   → 手动下载后放到 C:\Users\33432\.cache\torch\hub\checkpoints\ ：
     ResNet18: https://download.pytorch.org/models/resnet18-f37072fd.pth
     AlexNet:  https://download.pytorch.org/models/alexnet-owt-7be5be79.pth
